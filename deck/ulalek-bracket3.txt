// --- Decision log ---
// 2026-08-19 speed/resilience pass (goldfish sim showed slow 7-mana -> haymaker conversion;
// danger window is T5-8 archenemy turns, not T1-5):
//   OUT: Shamanic Revelation ({3}{G}{G} burst draw, double green too hard here, dead on critical turns),
//        Selective Obliteration (whiffs vs mono-color go-wide boards - the exact scenario needing a sweeper),
//        Endbringer (slow value, mediocre), Sire of Stagnation (colored 6-drop draw, paints a target),
//        Benthic Anomaly (weakest 7-drop).
//   IN:  Mind Stone, Fellwar Stone, Worn Powerstone (mana-positive rocks; Fellwar casts Ulalek since
//        his cost is all {C/x} hybrids), Elder Deep-Fiend (plain-{8} Eldrazi with flash, taps 4
//        permanents on cast - 8 with Ulalek's copy; MV8 triggers Unsealing draw-3 + Sanctum; emerge
//        {5}{U}{U} off a Spawn is a discount, not a requirement. Chosen over Metalwork Colossus after
//        owner review: sim showed Colossus wasn't carrying the speed gain, and Deep-Fiend is an
//        actual Eldrazi with a defensive mode. Sire of Stagnation stayed out on castability: {4}{U}{B}
//        is the only double-different-pip cost in the 99 and only 4 lands make B unconditionally),
//        Lightning Greaves (Ulalek eats every removal spell; Not of This World's {0} clause needs
//        power 7, so it never protects a naked Ulalek - Greaves does, for {2} once).
//   Same-script 20k-game sim, current -> new: Ulalek by T4 40%->48%; 7 mana by T6 31%->40%;
//   first 7+ threat median T9->T8. Combos re-verified via Commander Spellbook: still exactly the two
//   allowed late-game lines (Basalt+Forsaken Monument, Ulalek+Echoes+Unsealing). No new Game Changers;
//   the deck's 3 (cap) are Mana Vault, Ancient Tomb, Crop Rotation - Mana Drain is NOT on the
//   Feb-2026 GC list (earlier notes said otherwise).
// 2026-08-19 interaction pass (reassessment: interaction in the T3-6 window is a coin flip and
// quality was soft; early game ramps fine but is body-light, which is accepted archetype shape):
//   OUT: Null Elemental Blast (oracle check: hits MULTICOLORED spells/permanents only, not colored -
//        frequently dead vs mono/two-color decks), Eldrazi Mimic (2/1 whose upside needs a resolved
//        big Eldrazi already; weakest creature slot, trades down as a blocker).
//   IN:  Beast Within ({2}{G}, ~19 effective G sources; any-permanent instant answer live in the
//        danger window), Imprisoned in the Moon ({2}{U}; commander lock - moon'd commander stays on
//        battlefield, no command-zone recast. Caveat: the aura is colored, so our own All Is Dust /
//        Ugin Spirit Dragon -X destroy it and release the lock - time the sweeper accordingly.
//        Chosen over Song of the Dryads: same lock, 0.15EUR vs 4.71EUR, spreads pips off green).
//   No Game Changer or combo-policy implications; interaction 11 -> 12 slots.
